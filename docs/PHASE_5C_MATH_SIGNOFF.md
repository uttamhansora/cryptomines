## 1. Mathematical model

**Single payout path:** `win = baseBet × payoutBook / BOOK_SCALE` (100).

| Mechanism | Effect on `multiplierBook` / `payoutBook` |
|-----------|-------------------------------------------|
| Base ladder | After each safe pick `k`, set book from fair ladder targeting `RTP_BASE_SURVIVAL = TARGET_RTP` (0.96) **without** feature boosts |
| Streak chain | At safe pick **3**: +80 book (+0.80×). At pick **5**: +200 book (+2.00×). **Additive** on same book used for cashout |
| Symbol chains (α/β/γ) | On 3-symbol sequence match: +150 / +250 / +350 book via `applyChainBoost` — **same additive interpretation** |
| Organic vault | On 3× `VAULT` symbol: pick chest; `payoutBook = floor(baseMultiplierBook × factor / 100)` for factors 110–200 |
| Buy vault | Separate 50× bet product; chest values are **absolute** payout book (40×–56× bet), round ends on pick |

**Important:** Streak and symbol chain rewards are **not** separate bonus payouts; they increase the cashout multiplier book.

## 5. Organic vault economics

- **Trigger:** 3× `VAULT` on safe reveals (8% weight per safe cell assignment).
- **Chest factors:** 110, 125, 150, 175, 200 (uniform hidden winner).
- **Payout:** multiplicative on `baseMultiplierBook` at trigger (includes streak/symbol boosts applied on that pick).

Monte Carlo by depth (random symbol stream, cash after resolving vault when triggered): see `theoreticalAudit.organicVaultMonteCarlo` in `phase5c-sim-results.json`.

**Incremental EV** from vault is positive when triggered; combined with streak paths above, stacking worsens the over-100% conditional RTP.

## 13. >100% paths (explicit)

| Path | Why RTP > 100% |
|------|----------------|
| Cash at depth ≥3 with streak | Base ladder already ~96% at that depth **plus** +0.80×/+2.80× additive |
| Cash at depth 5+ | +2.80× on ~3.29× base → ~6.09× at P≈0.29 |
| + Symbol chain complete | Up to +3.50× additional book |
| + Organic vault | Multiplies already-inflated book |

**Root cause:** `RTP_BASE_SURVIVAL = TARGET_RTP` calibrates **base-only** conditional RTP while streak/symbol/vault **add** EV on the same cashout book.
