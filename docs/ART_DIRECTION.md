# Art Direction

Theme: **Premium Futuristic Crypto Vault**

- Graphite surfaces, cyan emissive accents, gold vault highlights
- Asset root: `frontend/public/assets/game/`
- Token objects under `crypto/` — dimensional SVG v2 (shared ring + gradient language)
- Dynamic FX: GSAP + single canvas burst (big win)

Avoid emoji, flat clip-art, inconsistent stroke weights.
